Precios del producto
El mayoreo se aplica solo cuando el cliente lleva 6+ piezas de este producto (sumando tallas/colores). Cada variante puede tener además su propio precio.
Variantes e inventario

Da de alta lo que realmente tienes: cada color con sus tallas y cuántas piezas hay de cada talla. Puedes agregar opciones (con/sin tirantes, largo…) y un precio propio por variante. Cuando una talla llega a 0, se marca agotada y no se puede pedir. El stock total se calcula solo. Si no agregas variantes, se usa el stock general de abajo.

Nueva variante

Marca las tallas que tienes en este color y pon cuántas piezas hay de cada una.

Se usa cuando el producto no tiene variantes. Si agregas variantes, el stock total se calcula sumando el inventario de cada talla.
